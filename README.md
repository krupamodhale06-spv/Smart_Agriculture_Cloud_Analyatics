# Smart Agriculture AI

Cloud-Based Intelligent Agriculture Decision Support System.

## Features

- AI Crop Recommendation
- Crop Probability Analysis
- Expected Yield Prediction
- Irrigation Recommendation
- Farm Risk Monitoring
- Soil Analytics
- Environmental Analytics
- Interactive Dashboard

## AI Models

- Random Forest Classifier
- Random Forest Regressor

## Technologies

- Python
- NumPy
- Scikit-learn
- Plotly
- Streamlit
- GitHub
- Streamlit Community Cloud

## Cloud Architecture

User → Internet → Streamlit Community Cloud → AI Application → AI Models → Dashboard
